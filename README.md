# Pinklie Beauty Cream Website

A modern, responsive landing page for Pinklie Beauty Cream, built with HTML and Tailwind CSS.

## Features
- **Modern Design**: Clean, elegant aesthetic with a soft pink color palette.
- **Responsive**: Looks great on mobile, tablet, and desktop.
- **Fast**: Uses Tailwind CSS via CDN for quick loading without a build step.
- **Interactive**: Includes smooth scrolling and hover effects.

## How to Run
Since this project uses static HTML and a CDN for Tailwind CSS, you don't need to install any software or servers (No Node.js required).

1. Simply locate the `index.html` file in this folder.
2. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, etc.).

## Customization
- **Images**: The images are currently sourced from Unsplash. You can replace the `src` attributes in the `index.html` file with your own local image paths (e.g., `images/my-product.jpg`).
- **Colors**: The theme colors are defined in the `<script>` tag within the `<head>` of `index.html`. You can adjust the `pinklie-primary` hex code to match your brand color exactly.
